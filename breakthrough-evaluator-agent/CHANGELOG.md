# Changelog

This file tracks the seed files under `playbook/`. Each seed carries a stamp on the line after its frontmatter:

```
<!-- seed: breakthrough-evaluator-agent <path inside the skill> v<version> -->
```

When you update, read every entry between the version in your copy's stamp and the version in the new seed. Each entry names the sections that changed, so the owner can rule on them one section at a time. The stamp in the owner's copy records which version they have ruled on, not which text they took.
